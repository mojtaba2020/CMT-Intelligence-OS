# Security policy (prototype)

This repository is an experimental local prototype, not a production service. Do not deploy it on an internet-facing host or put real customer/employer data into the demo.

Please do not post secrets, customer data, access tokens or live company records in GitHub issues. Before starting a real pilot, obtain written data-owner authorization and conduct a professional security review and method validation.

The local API has optional external image-extraction behavior only when configured by its operator. Do not put an API key in client-side code or commit it to Git.
