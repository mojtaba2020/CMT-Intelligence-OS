# CMT Field Companion v2.2 — Technician → Engineer (pilot)

نسخه 2.2 مسیر عملی ورود دستی آزمایش به آیفون و ارسال آفلاین برای مهندس را با **فایل JSON** اضافه می‌کند. این نسخه همگام‌سازی زنده، حساب کاربری واقعی، رمزنگاری انتهابه‌انتها، امضای دیجیتال یا اتصال به ElmTree ندارد.

1. تکنسین در `Capture` فرم خاک/بتن/گزارش روزانه/میلگرد می‌سازد و اعداد را وارد می‌کند.
2. در `Technician · Engineer handoff` → تب `Technician` فرم‌ها را انتخاب می‌کند و `Create review package` را می‌زند. فایل JSON در Files ذخیره می‌شود. عکس‌های ضمیمه در بسته نیستند.
3. فایل از **کانال انتقال تأییدشده** به مهندس داده می‌شود. در تب `Engineer` می‌تواند فایل را در دستگاه خودش Import کند؛ نمونه ساختگی با دکمه Demo نیز موجود است.
4. مهندس برای هر فرم یکی از گزینه‌های «برگشت برای اصلاح»، «اطلاعات بیشتر» یا «بازبینی برای مرحله بعد» را انتخاب می‌کند و یادداشت می‌نویسد. هیچ‌کدام تأیید رسمی مصالح نیست.
5. مهندس `Export engineer response` می‌زند و فایل JSON را برمی‌گرداند. تکنسین `Import engineer response` می‌کند؛ برنامه شناسه بسته و SHA-256 آن را کنترل می‌کند و در صورت تغییر فرم پس از ارسال، پاسخ را رد می‌کند.

SHA-256 فقط **کشف تغییر محتوای بسته** است و احراز هویت یا امنیت در برابر جعلِ عمدی نیست. اطلاعات هر دستگاه در localStorage همان مرورگر ذخیره می‌شوند و ممکن است با پاک‌کردن سایت، فضای کم یا حذف برنامه از دست بروند. قبل از استفاده از داده‌های واقعی باید مجوز شرکت، سیاست امنیتی، کاربران دارای حساب و سیستم همگام‌سازی/پشتیبان‌گیری تأییدشده فراهم شود.

این نسخه آزمایشی مخصوص داده‌های ساختگی و داده‌های دارای اجازه صریح است. عکس‌های واقعی GET یا اطلاعات مشتری در GitHub عمومی قرار نگرفته‌اند.
