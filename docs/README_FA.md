# CMT Field Companion v2.0 (PWA)

این یک اپ وب موبایل قابل نصب از روی Safari **پس از میزبانی HTTPS** است، نه برنامه native iOS/App Store.

## امکانات عملی
- ثبت فرم خاک، بتن، گزارش عمومی، میلگرد
- انتخاب/ثبت عکس با دوربین و فشرده‌سازی در دستگاه (بدون ارسال تصویر از برنامه)
- ذخیره اولیه محلی و تهیه پشتیبان JSON؛ توصیه به پشتیبان‌گیری مکرر، به‌خصوص روی iPhone/iCloud کم‌فضا
- هشدار خطاهای چگالی خشک، درصد تراکم، صفحه‌های مفقود، شناسه‌های تکراری و اختلاف تعداد آزمایش
- CSV بازبینی (نه فایل import رسمی ElmTree)
- واردکردن JSON پیشنهادی OCR نسخه 1.9 بدون تأیید خودکار
- نمونه کاملاً ساختگی برای امتحان قابلیت‌ها

## نصب PWA روی iPhone
۱. تمام فایل‌های این پوشه را بدون تغییر ساختار در یک نشانی HTTPS منتشر کنید. روش مناسب برای نمونه عمومی: GitHub Pages با پوشه `/docs` موجود در پروژه (بدون فرم یا عکس واقعی).
۲. وب‌سایت را در Safari باز کنید؛ Share → Add to Home Screen → Open as Web App → Add.
۳. برای اولین بار آنلاین باز کنید تا فایل‌های service worker ذخیره شوند. سپس مرورگری که از cache پشتیبانی می‌کند می‌تواند فایل‌های اپ را آفلاین باز کند.

**بازکردن HTML از Files یا داخل ChatGPT ممکن است پیش‌نمایش را نشان بدهد، ولی نصب PWA و ذخیره دائمی تضمین نمی‌شود.**

## محدودیت OCR و امنیت
- روی گوشی OCR دست‌خط زنده وجود ندارد. می‌توان پیش‌نویس JSON تولیدشده از OCR محلی رایانه را از Tools وارد کرد.
- برای داده‌های مجاز واقعی به حساب کاربری، رمزنگاری مناسب، کنترل ذخیره امن، رویه پاک‌سازی، ممیزی و تأیید شرکت نیاز است. مرورگر و GitHub Pages عمومی برای داده‌های محرمانه شرکت **تأیید نشده‌اند**.
- فایل تصاویر در پشتیبان JSON نیست؛ عکس‌ها روی همان دستگاه می‌مانند و ممکن است با پاک‌کردن داده مرورگر حذف شوند.
- هیچ نتیجه Pass/Fail یا گزارش رسمی مهندس توسط این برنامه صادر نمی‌شود.
