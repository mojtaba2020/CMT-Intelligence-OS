# ElmTree Interoperability Inquiry — independent developer questions

**Status:** No official ElmTree API, bulk results importer, or sandbox access has been confirmed for CMT Intelligence OS. The public website describes *QA data exports*, *mobile field entry*, and *customized report formats*; these claims do not establish a third-party write interface.

Official vendor sources:
- https://www.elmtreesystem.com/
- https://www.elmtreesystem.com/faq/
- https://www.elmtreesystem.com/contact-us/

## Request to vendor or authorized administrator

1. Is a nonproduction sandbox or synthetic-data demonstration account available to independent developers?
2. Are developer APIs, webhooks, service accounts, batch import endpoints, or approved file import formats supported for **test readings** (distinct from importing Word/Excel *report templates*)?
3. If read-only QA exports are available, what are supported formats, columns, units, stable identifiers, rate limits, and allowed uses?
4. Which workflows can a human reviewer approve before data enters ElmTree, and what distinguishes a draft from a signed official report?
5. Are there policies for vendor integration, confidentiality, data processing, security controls, test-specific versioning, and a commercial agreement?
6. Which features for technician capture and discrepancy review already exist in ElmTree, so an add-on can avoid duplicating them?

Do not request credential sharing or a copy of a production database. Do not reverse-engineer a private account or impersonate a company employee. Any third-party integration must be approved by the system owner and vendor.
