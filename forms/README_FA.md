# تطبیق ساختار چهار فرم میدانی با CMT Intelligence OS — بسته v1.7

این ماژول **فقط از ساختار بصری فرم‌های ارسال‌شده الهام گرفته** است. هیچ عکس، متن دست‌نویس واقعی، نام پروژه، شناسه یا نتیجه مشتری در سورس یا مثال‌ها قرار نگرفته است.

## چهار فرم شناسایی‌شده

1. **General Report**: هویت گزارش/پروژه، تاریخ و تکنسین، فعالیت‌ها و شمارش تست‌ها یا سیلندرها.
2. **Compressive Strength of Concrete**: اطلاعات نمونه‌گیری بتن، تأمین‌کننده، اسلامپ/هوا/دما و رکوردهای سیلندر، با ستون‌های جداگانه نتایج آزمایشگاه.
3. **Tests for In-Place Density of Compacted Soils**: داده‌های تکراری ردیف‌ها با صفحات سریالی، رطوبت، چگالی تر/خشک، حداکثر چگالی خشک، درصد تراکم گزارش‌شده و نتیجه ثبت‌شده توسط تکنسین.
4. **Rebar Observation**: گروه بازرسی کیفی با ردیف‌های میلگرد/المان/فاصله/ملاحظات.

## هدف بررسی

* گردآوری ایمن صفحات مرتبط بر اساس شناسه سری و شماره صفحه؛ تشخیص صفحه تکراری/ناقص.
* تطبیق شناسه پروژه، روز و شماره تست؛ تشخیص ردیف تکراری.
* چک حسابی چگالی خشک، رطوبت، تراکم و شمارش تست‌ها و سیلندرها؛ **صرفاً هشدار بررسی**، نه پذیرش ASTM.
* تولید گزارش HTML برای بازبینی انسانی، با escape کردن داده‌های ورودی.

## محدودیت مهم

این ماژول **OCR نیست**. ورودی آن JSON ساختاریافته‌ای است که می‌تواند بعداً از OCR با تأیید انسانی تولید شود. تا زمانی که مجوز روشن و محیط امن نداشته باشیم، عکس‌های واقعی شرکت را به سرویس AI یا مخزن عمومی منتقل نکنید. نام شرکت و الگوی فرم به‌معنی اجازه انتشار اسناد واقعی نیست.

خروجی CSV/JSON این بخش، فرمت رسمی واردکردن به ElmTree نیست. هیچ تأیید رسمی مهندسی، ASTM/AASHTO، محاسبه مجاز پذیرش مصالح یا امضای مهندس صادر نمی‌کند. تلورانس‌های ۱٫۵ pcf و ۰٫۵٪ فقط آستانه‌های قابل تنظیمِ پرچم QA آزمایشی هستند و نیازمند تأیید فنی پروژه‌اند.

## اجرای مثال با اطلاعات ساختگی

```bash
python -m forms.form_engine forms/examples/SYNTHETIC_PACKET.json --json-output forms/examples/SYNTHETIC_QA_RESULT.json --html-output forms/examples/SYNTHETIC_FORM_REVIEW.html
python -m pytest -q tests/test_form_templates_v17.py
```

برای انتشار عمومی فقط `templates.json`، کد، تست و نمونه ساختگی را منتقل کنید؛ عکس‌های واقعی ارسال‌شده در گفتگو داخل این بسته نیستند.
