# اجرای آزمایش OCR محلی نسخه 1.9

## پیش‌نیاز

- کامپیوتر Windows/macOS/Linux، Python 3.11 یا جدیدتر
- نصب موتور Tesseract OCR محلی (و زبان English). در ویندوز ممکن است لازم باشد مسیر نصب Tesseract را به PATH اضافه کنید.
- در پوشه اصلی پروژه: `python -m pip install -r requirements-ocr.txt`
- اجرای سرور فقط روی رایانه شخصی: `python -m uvicorn server.app:app --host 127.0.0.1 --port 8000`
- بازکردن `http://127.0.0.1:8000/ocr-lab` در مرورگر **همان کامپیوتر**.

## روش تست بدون دسترسی GET

1. نوع فرم **Concrete strength** و سیاست **Synthetic (demo)** را انتخاب کن.
2. روی **Load built-in synthetic photo** بزن.
3. تیک رضایت برای پردازش محلی را بزن؛ سپس **Run LOCAL OCR**.
4. مقدارهای Project, Date, Slump, Air Content, Concrete Temp پیشنهادی و خط مربوط به هرکدام را با تصویر مقایسه کن.
5. برای سنجش محافظت نرم‌افزار، قبل از بررسی انسانی روی **Screen reviewed packet** بزن: باید متوقف شود.
6. پس از بررسی تک‌تک فیلدها، تیک **Reviewed** را بزن؛ سپس غربالگری را اجرا و فایل JSON آزمایشی را ذخیره کن.
7. تغییر مقدار فیلد تیک بررسی همان فیلد را پاک می‌کند؛ برای تغییر شناسه فیلد هم بررسی قبلی باطل می‌شود.

هیچ‌یک از مثال‌ها متعلق به شرکت GET نیست. فیلدهایی که در تصویر نیستند حدس زده نمی‌شوند. مقدارهای چاپی واضح با دست‌خط فشرده و جدول‌های تست یکسان نیستند؛ برای داده واقعی باید **مجوز شرکت** و ارزیابی مستقل بگیریم. محیط demo احراز هویت کاربران سازمانی ندارد و نباید روی شبکه عمومی فعال شود.

## یادداشت برای آیفون

فایل HTML به‌تنهایی موتور OCR نیست. برای نمایش آسان روی آیفون از صفحه **Offline Replay** که همراه پروژه است استفاده کن؛ آن فقط اجرای ذخیره‌شده OCR روی نمونه ساختگی را بازپخش می‌کند و عکس جدیدی پردازش نمی‌کند.
