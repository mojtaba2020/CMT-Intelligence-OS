# اتصال رسمی ElmTree — وضعیت نسخه 2.0

این سند **یک قرارداد رسمی API نیست**؛ صرفاً فهرست سؤالات فنی برای مالک سیستم و فروشنده است.

## آنچه از منابع عمومی تأیید شده
- ElmTree ابزار ثبت میدانی مخصوص تکنسین و نرم‌افزار مدیریتی دارد.
- ابزار خروجی QA و قالب گزارش سفارشی در وب‌سایت معرفی شده.
- API عمومی برای خواندن/نوشتن نتایج آزمایش، schema رسمی Import یا sandbox توسعه‌دهنده در اطلاعات عمومی قابل تأیید نبود.

## شرایط فعال‌شدن اتصال
1. تأیید کتبی مالک داده و مدیر سیستم شرکت، تعیین محیط آزمایشی و محدودیت داده.
2. تعیین endpoint/format رسمی و مستندات نسخه‌بندی‌شده توسط ElmTree.
3. حساب service با کمترین دسترسی؛ Secret Manager و محدودیت شبکه؛ هرگز کلید در PWA یا GitHub.
4. ارسال فقط رکوردهای بازبینی‌شده پس از کنترل مغایرت، logging و rollback.
5. آزمایش با داده ساختگی و تطبیق 1:1 شناسه آزمایش، واحد، زمان، و پاسخ‌های خطا.

## وضعیت فعلی
- Backend writer عمداً fail-closed و مسدود است.
- خروجی JSON/CSV با برچسب REVIEW_ONLY صرفاً برای بازبینی انسانی است و قالب تأییدشده ElmTree نیست.
- هر ادعای اتصال زنده یا import بدون مجوز نادرست است.
