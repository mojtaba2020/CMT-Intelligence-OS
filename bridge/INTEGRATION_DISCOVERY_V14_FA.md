# چک‌لیست بررسی اتصال ElmTree (بدون دسترسی غیرمجاز)

برای مدیر IT/مسئول فنی GET یا پشتیبانی سازنده ElmTree:

1. آیا نسخه/مجوز شرکت امکان **خروجی CSV از نتایج QA** دارد؟ فایل نمونهٔ بی‌نام و بی‌اطلاعات مشتری و یک فرهنگ ستون‌ها ارائه می‌شود؟
2. آیا راه رسمی و مستند برای **واردکردن رکورد آزمایش از نرم‌افزار دیگر** وجود دارد؟ اگر نه، فقط خروجی/مقایسه آفلاین را بررسی کنیم.
3. آیا محیط آزمایشی (sandbox) و حساب آزمایشی جداگانه وجود دارد؟ آیا برای API مجوز تجاری جداگانه لازم است؟
4. قواعد شناسه یکتا، واحدها، اعشار، تاریخ/زمان، بازبینی مهندس، اصلاح نسخه، و گزارش‌های نهایی چه هستند؟
5. آیا داده‌ها قابل خروجی گرفتن بدون شناسه شخص، مشتری، آدرس و سایر اطلاعات محرمانه هستند؟ آیا انتقال به پردازشگر AI ثالث مجاز است؟
6. برای ارزیابی وقت، تعداد نتایج روزانه، میانگین زمان ورود دستی و زمان تصحیح خطا به‌شکل **آمار ناشناس** قابل ارائه است؟

**پایان مذاکره:** پاسخ رسمی/مستند تعیین می‌کند اتصال مجاز قابل توسعه است یا تنها مسیر تبادل و تطبیق آفلاین قابل استفاده خواهد بود. هیچ اتوماسیون کلیک، برداشت کوکی یا اتصال پنهانی انجام نشود.
