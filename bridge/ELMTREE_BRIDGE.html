میزکار تبادل داده با ElmTree

ساخت پیش‌نویس داده و پیدا کردن اختلاف‌ها؛ بدون اتصال، ارسال یا ویرایش اطلاعات در ElmTree

این برنامه قالب بومی ElmTree را نمی‌شناسد و هیچ API تأییدشده‌ای از ElmTree استفاده نمی‌کند. فرمت ستون‌ها صرفاً از فایل نقشه‌ای می‌آید که کاربر وارد کرده است. هیچ خروجی این صفحه نباید بدون موافقت شرکت و سازنده به‌عنوان فایل رسمی ورود داده استفاده شود.
به‌روزرسانی v1.4: عدم تطابق واحد اندازه‌گیری، کلید تکراری و مقدار عددی نامعتبر پیش از ساخت CSV مسدود می‌شوند. ساخت و راستی‌آزمایی بسته ZIP قابل اتکا از طریق دستور Python انجام می‌شود؛ این صفحه فقط پیش‌نمایش آفلاین است.

۱. انتخاب داده CMT

نسخه ساختگی را بارگذاری کن یا خروجی JSON مجاز نسخه چندکاربره را وارد کن. داده فقط در همین مرورگر خوانده می‌شود.

دکمه سرور فقط وقتی کار می‌کند که نسخه Python از مسیر 127.0.0.1 اجرا و حساب مهندس وارد شده باشد.

وضعیت اتصال به ElmTree

در این نسخه قابلیت تأییدشده فقط آماده‌سازی و مقایسه آفلاین است. برای اتصال مستقیم، باید با مجوز GET از سازنده درباره API، واردکردن فایل، قالب‌های داده، احراز هویت و محیط آزمایشی پرس‌وجو شود. هیچ کدام در این نسخه پیاده‌سازی یا ادعا نشده‌اند.

نه گزارش رسمی مهندسی، نه پذیرش مصالح، نه ارسال خودکار، نه دسترسی به اطلاعات شرکت.
