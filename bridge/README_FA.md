# CMT Intelligence OS v1.3 — پل تبادل داده ElmTree (آزمایشی)

## دقیقاً چه چیزی ساخته شده؟

**پل تبادل داده آفلاین و بدون نوشتن در سیستم خارجی** ساخته شده است، شامل:

1. دریافت JSON خروجی پایلوت CMT و استخراج رکوردهای بازبینی‌شده توسط فردی مستقل، با برچسب «authorized»؛ داده‌های ساختگی صرفاً با `--synthetic-demo`.
2. تنظیم تطبیق ستون‌ها از روی **فایل mapping که اپراتور مجاز تعریف می‌کند**؛ مثال داخل بسته، قالب رسمی ElmTree نیست.
3. خروجی CSV پیش‌نویس و گزارش SHA-256، همراه با واترمارک REVIEW_ONLY و شمارش رکوردهای حذف‌شده.
4. مقایسه CSV خروجی مجازِ سیستم دیگر با رکوردهای CMT و ارائه اختلاف در فیلدها، رکوردهای گمشده و کلیدهای تکراری؛ **بدون تطبیق حدسی**.
5. API فقط خواندنی `GET /api/pilot/export/bridge-candidates` که فقط برای نقش مهندس، بعد از کنترل یکپارچگی تاریخچه، رکوردهای مجاز و بازبینی‌شده را برمی‌گرداند.
6. میزکار مرورگری `bridge/ELMTREE_BRIDGE.html` با مثال‌های ساختگی؛ بدون ارتباط با ElmTree.

## چه چیزی ساخته نشده؟

- اتصال به API ElmTree، ورود خودکار به حساب ElmTree یا خواندن دیتابیس شرکت
- قالب مورد تأیید ElmTree برای Import یا Export (نیازمند نمونه دارای مجوز و تأیید سازنده)
- صدور گزارش رسمی، امضای حرفه‌ای مهندس، پذیرش مصالح یا اعتبارسنجی ASTM/AASHTO
- استقرار امن سازمانی یا مجوز استفاده از اطلاعات محرمانه شرکت GET

## اجرای نمایشی در مرورگر

فایل `bridge/ELMTREE_BRIDGE.html` را در مرورگر باز کنید؛ روی «بارگذاری مثال ساختگی» و سپس «ساخت پیش‌نویس CSV» کلیک کنید. برای نمایش یک اختلاف، «بارگذاری CSV ساختگی با اختلاف عمدی» و سپس «مقایسه رکوردها» را بزنید. در رکورد `TRAIN-1002` مقدار ۱۲۸ با ۱۲۵ متفاوت است. رکورد `TRAIN-1003` در وضعیت draft است و خروجی نمی‌شود.

نسخه آنلاینِ محلی بعد از اجرای سرور Python در `http://127.0.0.1:8000/bridge` در دسترس است. دسترسی سرور به ElmTree ندارد.

## اجرای قابل تکرار از خط فرمان

از مسیر ریشه پروژه:

```bash
python -m bridge.cli prepare \
  bridge/examples/SYNTHETIC_CMT_RECORDS.json \
  bridge/examples/SYNTHETIC_OPERATOR_PROFILE.json \
  --output bridge_review.csv --synthetic-demo

python -m bridge.cli compare \
  bridge/examples/SYNTHETIC_CMT_RECORDS.json \
  bridge/examples/SYNTHETIC_OPERATOR_PROFILE.json \
  bridge/examples/SYNTHETIC_OPERATOR_EXPORT_WITH_CONFLICT.csv \
  --output reconciliation.json --synthetic-demo
```

بدون پرچم `--synthetic-demo`، داده‌های منبع synthetic صادر نمی‌شوند. داده‌های واقعی فقط با اجازه و ناشناس‌سازی مجاز است. اگر فایلی از سامانه سازمان دریافت می‌کنید، برای مقایسه باید CSV دارای ستون‌های متناظر با mapping باشد؛ این برنامه *قالب ElmTree را حدس نمی‌زند*.

## اجرای سرور محلی و حساب مهندس

روش ساخت حساب و اجرای سرویس در `README_FA.md` ریشه پروژه است. مسیر `/api/pilot/export/bridge-candidates` فقط با ورود مهندس به سرویس محلی و پس از کنترل یکپارچگی مجاز است؛ هیچ رکوردی به نرم‌افزار بیرونی فرستاده نمی‌شود.

## نکات امنیت و کیفیت

- فایل‌ها را فقط روی دستگاه مجاز و با داده‌های ساختگی یا ناشناس‌شده و دارای مجوز باز کنید.
- خروجی CSV ممکن است برای نرم‌افزار مقصد **نامناسب** باشد؛ هیچ ادعایی درباره ورود مستقیم به ElmTree وجود ندارد.
- نشانه reviewed فقط به معنی بازبینی انسانی در نمونه آزمایشی است، نه تأیید رسمی مهندسی.
- فایل manifest در مرورگرهای فاقد `crypto.subtle`، هش `null` خواهد داشت. CLI Python همیشه SHA-256 می‌دهد.
- تطبیق رکوردها بر اساس شناسه صریح است. نبود/تکرار شناسه، تطبیق را متوقف می‌کند.
- فایل ورودی، حداکثر اندازه و تعداد ردیف کنترل می‌شود؛ با این‌حال این برنامه محصول امن تولیدی نیست.
